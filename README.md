# dnlbit/tap

Homebrew formulae for [dnlbit](https://github.com/dnlbit) tools.

```sh
brew install dnlbit/tap/usagebar
brew services start usagebar
```

| Formula | Description |
|---------|-------------|
| [usagebar](https://github.com/dnlbit/usagebar) | Menu bar monitor and MCP server for Claude Code usage limits |
